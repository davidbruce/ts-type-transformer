# F# findings from the library programs

**Status:** Fixed: 6, 7, 10, 11, 21, 24, 25, 26. Partly: 2 (the backslash; a case of an anonymous record still never matches), 18 (helper column options now have `Create`; `TableOptions_Core` still has none).

Kinds: runtime bug / can't express / awkward.

1. katex, awkward. `macros: JsRecord<string, StringOrObjectOrFn>` is wanted, but `JsRecord` (Bindings.Prelude.fs) has only an indexer, no constructor or `Create`: `JsRecord<_,_>.Create ()` does not compile ("does not define the field, constructor or member 'Create'"). Worked around with `createEmpty<JsRecord<..>>` from Fable.Core.JsInterop.
2. katex, runtime bug. `TrustContext` (Bindings.01.main.fs:95 etc., e.g. `Object_`) has `CaseTest("$0 != null && String($0[\"command\"]) === \"\\href\"")`: the F# string holds `"\href"`, which as JavaScript is `"href"` (backslash lost), so the test is never true; a `trust` callback matching `TrustContext.Object_ o` never sees the context (Fable even emits `if (false && ...)`). Also awkward: the cases are named `Object`, `Object_`, ... `Object______`, indistinguishable by name.
3. marked, awkward. `MarkedOptions<_,_>` and `MarkedExtension<_,_>` (Bindings.01.main.fs, "type MarkedOptions") have no `Create`, though every other option bag has; options are made with `getDefaults<string,string> ()` then mutated (`o.breaks <- Some true`), an extension with `createEmpty`.
4. marked, awkward. `Token` is `U9<Tokens.Blockquote, ..., Tokens.Generic>` (Bindings.02.Tokens.fs:244), a union discriminated by the string field `type`, but nothing reads it: there is no tagged-union match for it (other unions get `TypeScriptTaggedUnion`), and the erased cases cannot be tested. To read a token it is cast with `unbox<Tokens.Generic>` (type/raw) or `unbox<Tokens.Heading>`.
5. marked, can't express. `marked.parse` / `Bindings.Values.parse` (Bindings.Values.fs, Bindings.03.marked.fs), `Marked#parse` and `Marked#parseInline` (Bindings.01.main.fs, `abstract parse: obj`) are typed `obj`: the main entry points of an instance cannot be called. (Only the function `marked (src, ?options)` and `parseInline.Invoke` work.)
6. marked, can't express. `use` with a renderer/hooks: `MarkedExtension.renderer` (Bindings.02.Tokens.fs:606) is an anonymous record whose callbacks are typed `ResizeArray<Tokens.Heading> -> ...` (the TS rest parameters `...args: Parameters<>` taken as one array argument, but marked calls them with the token itself), and a `{| ... |}` needs every one of ~25 fields. A renderer override cannot be written correctly. Same for `hooks` (`ResizeArray<string> -> StringOrPromise`). Only `walkTokens` (typed `(Token -> ...) option option`, set as `Some (Some f)`) works.
7. date_fns, awkward. `DateValues` (Bindings.01.main.fs, for `set (date, values)`) has no `Create`, unlike `Duration`/`Interval`; made with `createEmpty<DateValues>` and field assignment.
8. date_fns, can't express. `interval start end` returns `Interval<JS.Date, JS.Date>` (Bindings.Values.fs, `static member interval`), but every function taking an interval wants `Interval<DateArg<JS.Date>, DateArg<JS.Date>>`: `intervalToDuration (interval a b)` fails with "Type constraint mismatch ... 'Interval<JS.Date,JS.Date>' is not compatible with 'Interval<DateArg<JS.Date>,DateArg<JS.Date>>'". The result of `interval` is unusable; `Interval.Create (U3.Case1 a, U3.Case1 b)` is the workaround (so `interval` is left out of use, only called).
9. date_fns, awkward. Option types that `inherit` another (`FormatDistanceOptions`, Bindings.01.main.fs:268, and the like) have no `Create` (plain `[<AllowNullLiteral>]` class, not `Interface` + `ParamObject`); made with `createEmpty<FormatDistanceOptions>`. Also `eachDayOfInterval` returns `ResizeArray<DateOrStringOrNumber>` where JS returns Dates, and `isValid` takes `obj`.
10. node, runtime bug. Every `path` function and value (Bindings.06.path.fs: `[<Import("path", "path"); Emit("$0.join($1...)")>] static member join`) imports the named export `path` of "path", which node:path does not have: the compiled program dies at load with `SyntaxError: The requested module 'path' does not provide an export named 'path'`. Nothing of `path` can be used (the default export is what is wanted).
11. node, runtime bug. `EventEmitter.on/once/addListener/removeListener` take `listener: (ResizeArray<obj> -> unit)` (Bindings.05.NodeJS_and_16_more.fs:123-138): the rest parameters `...args: any[]` as one array, but Node calls a listener with the arguments separately, so `args.[0]` on `emit ("ping", "two")` is "t" (the first character of the string). A listener cannot read what was emitted.
12. node, awkward. `Fs.mkdirSync (p)` and `Fs.readdirSync (p)` are ambiguous (every overload has optional options; Bindings.05.NodeJS_and_16_more.fs:2353-2355, 2369-2373): "A unique overload ... could not be determined", and a return-type annotation does not select. Worked around by giving an options value (`{| recursive = true; mode = None |}`, `U2.Case1 {| encoding = None; withFileTypes = None; recursive = None |}`), the latter returning `ResizeArray<StringOrNonSharedBuffer>` instead of strings.
13. node, can't express. `global_BufferEncoding` (Bindings.Prelude.fs:115) and `Uint8Array<'T>` (:112) are empty interfaces: `readFileSync (file, "utf8")`, `writeFileSync (f, d, "utf8")` and `buf.toString "utf8"` cannot be written (no way to make an encoding from a string), and a Buffer has no members (no length, no bytes). The test reads a file as a Buffer and calls its default `toString ()`.
14. three, can't express. Methods taking `Vector3Like` / `QuaternionLike` (`Vector3.add/dot/cross/distanceTo/equals/lerp/applyAxisAngle`, `Quaternion.setFromAxisAngle`, `Vector3.applyQuaternion` ...; Bindings.02.main.fs:5834 ff.) do not accept a `Vector3` / `Quaternion`: "The type 'Vector3' is not compatible with the type 'Vector3Like'" (the TS types are structural, the F# interfaces are not related). The commonest three.js call, `a.add b`, does not compile; worked around with `unbox<Vector3Like> v` (or `Vector3Like.Create (x, y, z)`, a copy).
15. rapier, awkward. `World.castRay` (Bindings.01.main.fs, `abstract castRay: ... -> RayColliderHit`) returns null when nothing is hit but is typed as a plain `RayColliderHit` (not `option`), so a miss must be found with `isNull (box hit)`; same for `RigidBody.parent`-style getters like `World.getRigidBody`. (Nothing else of the rapier API went wrong: init/promise, World, bodies, colliders, stepping and ray casts all work.)
16. tanstack_table, can't express. `constructTable` needs `features.coreReactivityFeature`, which exists only in the package's subpath export `@tanstack/table-core/store-reactivity-bindings` (`storeReactivityBindings ()`); without it `constructTable` throws "Cannot read properties of undefined (reading 'coreReactivityFeature')". Only the main entry is bound, so the program declares its own `[<Import("storeReactivityBindings", "@tanstack/table-core/store-reactivity-bindings")>]` (using the bound type `TableReactivityBindings`).
17. tanstack_table, runtime bug. `TableFeatures.Create (coreRowModel = createCoreRowModel<TableFeatures, obj> (), sortedRowModel = ...)` (Bindings.01.main.fs, `TableFeatures`, ~line 954): (a) does not compile, the factory is `Table<TableFeatures,obj> -> unit -> RowModel<..>` where the field wants `obj -> unit -> RowModel<obj,obj>` ("Type constraint mismatch"); (b) cast, it compiles but Fable wraps the F# function value (`uncurry2 (arg => f arg)`), dropping the `feature` property of the factory the library reads, and the table throws "table._rowModels.coreRowModel is not a function". Worked around by making the features with `createObj` and boxing the factories.
18. tanstack_table, can't express. `TableOptions_Core<_,_>` (Bindings.01.main.fs:1085, an intersection: four `inherit`s) has no `Create`, and its fields (`features`, `data`, `columns`) are read-only, and `ColumnHelper.accessor` returns `ColumnHelperAccessorResult` (a U8 of anonymous records), which is not the `ColumnDefBase_Core` that `columns` takes: a table's options cannot be written. Worked around with `unbox (createObj [...])`. (The helper's column argument `U6.Case2 {| getUniqueValues = None; footer = None; cell = None; meta = None; header = "Name"; id = None |}` is also awkward: an anonymous record needs every field.)
19. tanstack_table, can't express. `Table<'F,'D>` is `Table_Core` only: the feature APIs (`setSorting`: `Table_RowSorting`, `Column_RowSorting.toggleSorting`/`getCanSort`) are on other interfaces that a table is not, so sorting a table needs `unbox<Table_RowSorting<..>> table`; `table.store` is `ReadonlyStore<TableState>`, an empty interface (its type is from @tanstack/store, Bindings.Prelude.fs:52), so the state is read with `(box table.store)?get ()`.
20. leaflet, awkward. `PolylineOptions.Create (color = Some "red", weight = Some 5.0)` does not compile: "A unique overload for method 'Create' could not be determined" (candidates `PathOptions.Create` and `PolylineOptions.Create`; the static `Create` of an options type is inherited by the types that extend it, and both take `?color`). Same for any option type with a base that has a `Create` (Bindings.02.leaflet.fs:1084-1125 ff.). Worked around with `createEmpty<PolylineOptions>` and field assignment, where every field is `float option option`.
21. konva, compile error (no program possible). The generated bindings do not compile: Bindings.02.konva.fs defines `module Konva` containing `type KonvaStatic` twice (lines 8 and 1054) and `let Konva: KonvaStatic` twice (72 and 1099): "Duplicate definition of type, exception or module 'KonvaStatic'" (FS0037). Even `module Test` alone fails, so tests/libraries/konva/test.fs cannot run.
22. pixi, can't express. `Texture.WHITE` is `Texture<BufferImageSource>`, but `Sprite.Create` / `SpriteOptionsOrTexture.Texture` take `Texture<TextureSource<obj>>`: "The type 'TextureSource<obj>' does not match the type 'BufferImageSource'" (Bindings.03.PixiMixins_and_1_more.fs:7295 vs 15778). Generic classes are invariant in F#, so a Sprite cannot be made from a texture that is a subclass instance; worked around with `unbox`.
23. pixi, can't express. A `Container` is an `EventEmitter<ContainerEvents, obj>` (Bindings.03...:9965), but `EventEmitter<_,_>` is an empty interface (Bindings.Prelude.fs:159, the type is from eventemitter3): no `on`, `emit`, `off` on any display object, Application ticker or renderer.
24. pixi, can't express. `Application.init` takes `?options: {| backgroundColor: ...; background: ...; ... |}` an anonymous record of about 85 fields, all required (Bindings.03...:713), and `ApplicationOptions.Create` takes ~90 required arguments: no application can be configured (a canvas, size, background); only the no-argument `app.init ()` can be called. Also awkward: `Matrix.apply` is generic in its result (`apply<'P>`), needing `m.apply<Point> (...)` to avoid a value restriction.
25. echarts, can't express. Option types are anonymous records with every field required: `BarSeriesOption` (Bindings.01.echarts_and_1_more.fs:92), `EChartsOptionXAxis` (:11454), `EChartsInitOpts` (:411), the `getDataURL` opts ... each of ~100 fields (all `option`), so a bar series cannot be written; `EChartsOption`'s fields (`series: EChartsOptionSeries` = U9 of those records) have the same problem. Worked around with an object made by `createObj` and `unbox<EChartsOption>`. (Also: F# arrays of numbers compile to typed arrays, which ECharts refuses as series data: `ResizeArray` is used.)
26. echarts, runtime bug. `chart.on (event, handler)` (Bindings.01.echarts_and_1_more.fs:5532, `Eventful.on`): handler typed `ResizeArray<obj> -> BooleanOrVoid` (the TS rest parameters as an array) but ECharts calls it with the arguments one by one: reading `args.[0]` of `chart.trigger ("ping", 42)` does not give 42. Same shape as finding 11 (node EventEmitter).
27. echarts, awkward. `chart.setOption option` does not compile: two overloads `setOption (option, ?notMerge, ?lazyUpdate)` and `setOption (option, ?opts)` are ambiguous; `chart.setOption (option, false)` picks the first. Also `HTMLElement` (Bindings.Prelude.fs) is an empty interface, so the element `TestPage.element` returns has no members (no `querySelector`, `style`).
28. prosemirror, can't express. The `Transform` methods that return `this` in TypeScript (`addMark`, `removeMark`, `delete`, `replace`, `insert`, `split` ...; Bindings.03.prosemirror-transform.fs) return `Transform`, even on a `Transaction`: `state.apply (state.tr.addMark (1.0, 4.0, mark))` fails with "The type 'Transform' is not compatible with the type 'Transaction'". Worked around by calling them as statements on a transaction held in a value. (`Transaction.insertText`, declared on Transaction, does return Transaction.) Also awkward: `Attrs` is `JsRecord<string, obj>`, which cannot be constructed (finding 1).
