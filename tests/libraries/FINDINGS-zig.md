# Zig bindings: findings from the library programs

**Status:** Fixed: 4, 8, 10, 11, 12, 16, 18, 20; partly 6.

Paths are in `target/e2e/libraries/<lib>-zig-run/` (regenerated by each run). Kinds: **runtime bug** (the glue does the wrong
thing), **can't express** (valid usage with no Zig spelling, or a compile error), **awkward** (works, with a workaround).

1. **katex, can't express.** `KatexOptions.macros` (`Record<string, string | object | fn>`) is bound as `KatexOptions_macros` with only
   `create()` (`areas/main.zig:232`): no setAt, so a macro like `\RR` cannot be defined.
2. **katex, can't express (compile error).** A callback whose parameter is a union cannot be written. `trust: (context: TrustContext) => boolean`:
   `types.zig:93-100`, `TrustContext_to_boolean_fn.Fn = fn (?*anyopaque, TrustContext) bool` but `call` passes `JsValue{ .h = a0 }`
   ("expected type 'types.TrustContext', found 'runtime.JsValue'"). The generated `from` never compiles when instantiated.
3. **marked, can't express (compile error).** `Token` (a union with a catch-all `Tokens_Generic`) has `tag` but no `fromHandle`/`lent`
   (`types.zig:77`). `TokensList.iterate()` fails with "union 'types.Token' has no member named 'fromHandle'" (`runtime.zig:118`), and
   `Token_to_void_or_..._fn` (walkTokens, `types.zig:723-732`) has the same JsValue-for-union mismatch as 2, so `walkTokens` cannot be used.
   Workaround for reading: `tokens.getAt(i)` and a hand cast to `b.tokens.Heading` etc.
4. **marked, awkward (wrong type).** Renderer and hook callbacks taking `...args: Parameters<X>` are typed with the tuple:
   `MarkedExtension_renderer_heading.Fn = fn (?*anyopaque, JsTuple(&.{ Tokens_Heading })) JsValue` (`types.zig:932`), `hooks_preprocess`
   takes a `JsArray` (`types.zig:811`). The glue passes the first argument itself (the token / the markdown string), so
   `args.get(0)` reads `token[0]` (null). The handle must be reinterpreted by hand (`.{ .h = args.h }`).
5. **marked, can't express.** The package's top-level `parse()` and `parseInline()` cannot be called: `parseInline` is a struct with
   `invoke` methods (`areas/main.zig:706`) but nothing returns one; `getParse()` returns `JsValue` (`:1388`). A `Marked` instance's `getParse()` works.
6. **node, awkward.** `fs.mkdirSync` with `{ recursive: true }` is spread over three overloads; the plain one
   (`areas/fs.zig:1628`) cannot take `MakeDirectoryOptions`, `mkdirSyncWithOptNumberOrStringOrMakeDirectoryOptions` does.
7. **node, awkward.** String-literal-union parameters appear as an opaque handle: `readFileSyncOrBufferEncoding(path, ... global_BufferEncoding)`
   (`areas/fs.zig:1684`, `types.zig:1349 extern struct { h: u32 }`) although a `BufferEncoding` enum exists (`types.zig:101`); the string is made by hand.
8. **node, runtime bug.** Every `path` function fails: the glue calls `PK["path"].path.join(...)` (`glue.mjs:396`, also normalize, basename, extname,
   resolve, relative, parse, format, sep...) but the module `node:path` has `join` on itself, so `.path` is undefined
   ("Cannot read properties of undefined (reading 'join')"). `path` checks are left out of the program.
9. **node, runtime bug.** An omitted optional argument is passed as `undefined`, not omitted. `EventEmitter.removeAllListeners(null)`
   (`glue.mjs:372`: `removeAllListeners(a0 === 0 ? undefined : ...)`) removes nothing, because Node tests `arguments.length`.
10. **node, runtime bug + awkward.** `listener: (...args: any[]) => void` is `any_array_fn` taking a `JsArray` (`types.zig:2143`), but the glue forwards only
    the first argument, as itself (`glue.mjs:355`: `(a0) => f(ctx, ref(a0))`). Further emit arguments are lost; the handle must be read as a value.
11. **three, awkward.** A `Vector3` where the interface `Vector3Like` (or `Quaternion` for `QuaternionLike`) is wanted has no conversion
    (`Vector3Like` in `areas/main.zig:22872` has no `as*` from `Vector3`); the handle is reinterpreted (`.{ .h = v.h }`). Class-to-base has `asObject3D()`.
12. **tanstack_table / prosemirror / marked, can't express.** A function-typed value coming back from JavaScript cannot be called: type aliases of
    function types (`ColumnHelper_accessor` in `types.zig`, `Table_Core_to_fn_fn` from `createCoreRowModel()` `areas/main.zig:5783`,
    `createSortedRowModel()`, prosemirror `EditorView.getDispatch() -> Transaction_fn`) have only `from` (Zig to JS) and no `invoke`. Callable objects
    with a call signature (konva `GetSet`, `CreatedSortFn`) do get `invoke`. `createColumnHelper().accessor(...)` is unusable.
13. **tanstack_table, can't express.** No table can be built (v9 core). `constructTable` (`areas/main.zig:5773`) needs `features.coreReactivityFeature`
    whose `createWritableAtom` returns an `Atom`, but `Atom`/`ReadonlyAtom` are opaque `extern struct { h: u32 }` (`types.zig:410`, from the unbound
    `@tanstack/store`), nothing can make one, `storeReactivityBindings` lives in an unbound subpath, and `TableOptions` exposes `features`, `data`, `state` read-only
    (`areas/main.zig:2616`, only `getData`). The program checks state/column-def objects, features, `cloneState`, a sort fn, and the library's TypeError.
14. **pixi / leaflet, awkward.** Only the direct parent has an `as*` conversion on some classes: `Graphics` has `asViewContainer` (not `asContainer`,
    `areas/pixi.js.zig:26737`), `Circle` has `asCircleMarker` (not `asLayer`, `areas/leaflet.zig:4264`), while `CircleMarker` has all its ancestors.
    Reaching `Container` methods takes `g.asViewContainer().asContainer()`; merged-interface members (addChild, getBounds, toGlobal, width) live on
    `PixiMixins_Container` and need another `asPixiMixins_Container()`.
15. **pixi, runtime bug (types lie).** `Point.add/subtract/dot/cross/magnitude/normalize/...` (the `Vector2Math` mixin, `areas/pixi.js.zig:9131`) are bound, but exist
    only after `import 'pixi.js/math-extras'`, which nothing can load: "get(...).magnitude is not a function".
16. **echarts, can't express / runtime bug.** `BarSeriesOption.create()` returns `{}` (`glue.mjs:459`); the discriminant `type: "bar"` is only a Zig
    constant (`areas/echarts.zig:1132`), and there is no setter, so `setOption` throws "Unknown series undefined". Workaround: write it through
    `EChartsCoreOption.setAt("type", ...)` on the same handle.
17. **konva, awkward.** `GetSet` properties have setters that take a `GetSet` (`areas/konva.zig:1788 setFill(self, value_: GetSet)`), i.e. the accessor
    function itself, not a colour or number; a value is set with `getFill().invoke2(value)`.
18. **konva, runtime bug (blocks the program).** The package only has `export default Konva`, but the glue calls `new (PK["konva"].Stage)(...)`, `PK["konva"].Layer`
    (`glue.mjs:324`): "PK.konva.Stage is not a constructor". No class can be constructed, so nothing but plain-object configs can run. The intended program is
    in `test.zig` as `pending()`.
19. **prosemirror, awkward.** There is no way to write an object or array literal: `SchemaSpec.nodes/marks` are `JsValue` (`areas/prosemirror-model.zig:362`),
    `Node.fromJSON` takes `JsValue`; an index-signature type (`NodeSpec`/`Attrs` + `setAt`) stands in as a dictionary.
20. **prosemirror, can't express.** `EditorView.dispatch(tr)` is `getDispatch() -> Transaction_fn` (`areas/prosemirror-view.zig:294`), not callable (12).
21. **leaflet, awkward.** An optional named `fn` must be written `.@"fn" = x`; event names are picked by overload (`offWithCanvasAddEventListenerTypeClick`).
22. **echarts / pixi, awkward.** The namespace of a name is unpredictable: `echarts.EChartsOption` is in the package struct, but nested/synthetic types
    (`XAXisComponentOption_xAxis`, `Application_init_options`, callback types) are at the top of `bindings.zig`; with a `test-page` package also bound,
    packages' names move under a struct (`b.leaflet.latLng`) that the compile-only output (`<lib>-zig/`) does not have.

Also noted, not a bug: a callback's returned handle is given to JavaScript, so returning a lent argument needs `jsRetain` (prosemirror plugin `apply`); forgetting
it shows as "handle N released twice".
